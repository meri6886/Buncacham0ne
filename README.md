Deploy GitHub Pages:
1. Tạo repo mới trên GitHub.
2. Upload toàn bộ nội dung của thư mục này, giữ nguyên cấu trúc.
3. Vào Settings → Pages.
4. Build and deployment → Deploy from a branch.
5. Chọn Branch: main / root.
6. Save.
7. Chờ khoảng 1–3 phút rồi mở URL GitHub Pages.

Google Sites:
- Vào Google Sites → Chèn → Nhúng → Theo URL.
- Dán URL GitHub Pages vừa publish.
